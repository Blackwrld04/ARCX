[ 03 // ARCHITECTURE ]

Why & How?

Legacy security APIs demand thousands per month in enterprise lock-ins. ArcX unlocks sovereign, pay-per-query intelligence for autonomous agents.

01

Sub-Second Arc Settlement

Built directly on Circle's Arc Mainnet (Chain 5042). Native USDC gas eliminates token conversion volatility with sub-second deterministic finality.

02

Zero Gas for Buyers

Clients sign EIP-3009 authorizations off-chain using standard EIP-712 typing. The ArcX facilitator executes receiveWithAuthorization and absorbs the gas fee floor.

03

Replay-Proof Cryptography

The authorization nonce cryptographically binds a 16-byte random salt with the HTTP method and requested URI. Cross-endpoint signature reuse is mathematically impossible.
